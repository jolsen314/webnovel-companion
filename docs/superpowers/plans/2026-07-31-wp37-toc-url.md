# WP-37 — Per-series chapter-TOC URL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give each `Source` an optional `tocUrl` so backfill and page-watch fetch the real chapter list when a series' landing page isn't its table of contents — auto-discovered at add-time and self-healed at backfill.

**Architecture:** A pure `findTocUrl(html, baseUrl)` anchor-text heuristic (in `lib/feeds/discover.ts`) locates the "table of contents" link on a landing page. `addSeries` calls it on the already-fetched page body and persists `tocUrl`; `backfillFromToc` self-heals a null `tocUrl` by discovering + following the link one hop and persisting it. Consumers read `tocUrl ?? url` (backfill) and `feedUrl ?? tocUrl ?? url` (page-watch poll). The poll stays pure/cheap — it never calls `findTocUrl`.

**Tech Stack:** TypeScript (strict), Prisma + Postgres (Neon), Vitest (unit + integration projects). `lib/` stays Next-free and pure.

## Global Constraints

- `src/lib/**` stays pure — no `next`/`prisma`/`fs`/network imports (design rule). `findTocUrl` is a pure HTML-string function.
- TDD for all `lib/` logic — failing test first, watch it fail for the right reason, then implement (agreement #2).
- Verify before claiming done — `npm test` + `npm run typecheck` with fresh output in the same message (agreement #3).
- Committed content stays anonymous — no real site/series names in code, tests, or committed docs; use reserved `.example` domains and generic works (memory: no-real-site-names). Real URLs live only in the gitignored local testing notes.
- `tocUrl` is nullable; `null` means "landing page IS the TOC" → consumers fall back to `url`. One field, shared with WP-34 (do not add a second TOC field).
- Migration workflow: `npm run db:migrate` (= `prisma migrate dev`) against the local `webnovel_dev` DB; `prisma generate` runs on install. Integration tests run against `webnovel_test` (see `tests/integration/setup.ts`).

Add to `src/lib/feeds/discover.ts` (below `discoverFeeds`, reusing `attr`):

```typescript
/** Anchor texts that denote a link to the chapter table of contents (WP-37). Anchored so a
 *  bare "Chapter N" / "Chapter 3: Index …" link is never mistaken for the TOC itself. */
const TOC_LINK_TEXT = /^(?:table of contents|chapter list|all chapters|toc|index)$/i;

/** Strip tags, decode nothing (labels are plain text), collapse whitespace, trim. */
function linkText(anchor: string): string {
  return anchor
    .replace(/<[^>]*>/g, '')
    .replace(/\s+/g, ' ')
    .trim();
}

/**
 * Find the landing page's link to its chapter table of contents, when the TOC lives on a
 * separate page (WP-37). Pure. Returns the first same-host, absolute URL whose anchor text
 * matches `TOC_LINK_TEXT` and that isn't the current page; else null (the landing page IS the
 * TOC, or no link is discoverable → caller falls back to `url`).
 */
export function findTocUrl(html: string, baseUrl: string): string | null {
  let base: URL;
  try {
    base = new URL(baseUrl);
  } catch {
    return null;
  }
  const current = `${base.origin}${base.pathname}`;
  for (const anchor of html.match(/<a\b[^>]*>[\s\S]*?<\/a>/gi) ?? []) {
    const openTag = anchor.match(/<a\b[^>]*>/i)?.[0] ?? '';
    const href = attr(openTag, 'href');
    if (!href) continue;
    if (!TOC_LINK_TEXT.test(linkText(anchor))) continue;
    let resolved: URL;
    try {
      resolved = new URL(href, base);
    } catch {
      continue;
    }
    if (resolved.host !== base.host) continue; // same-host only
    if (`${resolved.origin}${resolved.pathname}` === current) continue; // not a self-link
    return resolved.toString();
  }
  return null;
}
```

```typescript
  // WP-37: fetch the real TOC page. If tocUrl is unset (pre-WP-37 series, or a landing page
  // that only later linked a TOC), self-heal: fetch the landing page, discover its TOC link,
  // follow it one hop, and persist tocUrl so future backfills/polls go straight there.
  let tocUrl = source.tocUrl ?? source.url;
  let res = await fetchImpl(tocUrl, {});
  if (res.outcome !== 'SUCCESS' || res.notModified) return { added: 0, reconciled: 0 };

  let discoveredTocUrl: string | null = null;
  if (source.tocUrl == null) {
    const link = findTocUrl(res.body, source.url);
    if (link != null && link !== tocUrl) {
      const followed = await fetchImpl(link, {});
      if (followed.outcome === 'SUCCESS' && !followed.notModified) {
        tocUrl = link;
        res = followed;
        discoveredTocUrl = link;
      }
    }
  }

  const toc = parseToc(res.body, tocUrl);
```
